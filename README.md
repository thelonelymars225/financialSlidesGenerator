# financialSlidesGenerator

An affordable, subscription-based tool that turns company reports, uploaded files, or pasted text into useful business deliverables.

The first product focuses on presentation generation: extract the source material, produce source-grounded financial analysis, fit the result into controlled slide layouts, and export a PowerPoint presentation. Future versions may extend the same analysis and generation foundation to Excel and other Office workflows.

## Product direction

- Make professional business-document generation substantially cheaper and simpler.
- Preserve financial accuracy, units, reporting periods, and source references.
- Use cost-efficient models without accepting measurable quality degradation.
- Keep model output structured and constrain presentation generation through a deterministic harness.
- Support future Office outputs without coupling the analysis layer to one renderer.

## Initial workflow

1. Accept an uploaded file or pasted text.
2. Extract text, tables, and source references.
3. Retrieve the relevant report sections.
4. Generate validated, structured business analysis.
5. Map the analysis into approved presentation layouts.
6. Render compatible HTML and export the final PowerPoint.
7. Validate the output and apply bounded, targeted repairs when required.
