# Golden fixtures

Each fixture should use synthetic, licensed, anonymized, or explicitly opted-in
source material and include:

- expected facts, values, units, periods, and source locations;
- required material findings;
- forbidden unsupported claims;
- the expected structured analysis contract;
- an approved reference deck or layout assertions where appropriate.

The MVP target in the BRD is at least 20 representative fixtures. Do not add
private customer or company data to this directory.
